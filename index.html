Overview Modul

Modul Praktikum Pemrograman Fisika

Dua belas modul yang dipelajari sepanjang semester, dari pengenalan Python hingga proyek akhir berbasis Project Based Learning.

M1

Pengenalan Python, Jupyter, dan Markdown

Mengenal environment Python, Jupyter Notebook, dan cara menulis dokumentasi dengan Markdown.

Variabel, Tipe Data, dan Dasar I/O

M2

Memahami variabel, tipe data dasar, serta perintah input dan output di Python.

M3

Operasi Matematika & Formatting Angka

Melakukan operasi aritmatika dan memformat tampilan angka pada output program.

Perancangan Algoritma & Flowchart

M4

Merancang alur logika program dalam bentuk algoritma dan flowchart.

M5

Struktur Kendali Percabangan

Menggunakan if, elif, dan else untuk mengambil keputusan dalam program.

Struktur Pengulangan (Looping)

M6

Menerapkan perulangan for dan while untuk proses yang berulang.

M7

Fungsi & Modularisasi Kode

Membuat fungsi untuk menyusun kode yang modular dan mudah dipakai ulang.

Struktur Data List, Array, dan Matriks

M8

Mengelola kumpulan data dengan list, array, dan matriks.

M9

Pengolahan Data Array & Operasi Matriks

Melakukan operasi matriks dan pengolahan data array menggunakan NumPy.

Membaca dan Menulis File (File I/O)

M10

Membaca dan menulis data dari/ke file eksternal seperti .txt dan .csv.

M11

Visualisasi & Plot Grafik Data

Memvisualisasikan data fisika dalam bentuk grafik menggunakan Matplotlib.

Project Based Learning (PBL)

M12

Mengerjakan proyek akhir yang mengintegrasikan seluruh materi yang telah dipelajari.
